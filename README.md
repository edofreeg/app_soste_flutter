# Soste Autisti (Flutter)

Registra autista, luogo, arrivo, partenza e intervallo di sosta. Export CSV con separatore `;`.

Il repository contiene solo `lib/`, `pubspec.yaml` e il workflow: la cartella `android/`
viene generata da GitHub Actions a ogni build.

Release: `git tag v1.0.0 && git push origin v1.0.0`
